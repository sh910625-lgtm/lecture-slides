확률변수

확률변수

어떤 시행에서 표본공간의 각 근원사건에 하나의 실수를 대응시키는 관계

→ 앞면이 나온 횟수 X는 확률변수

확률변수는 보통 X, Y, Z, …로, 확률변수가 취하는 값은 x, y, z, … 또는 x₁, x₂, …으로 나타낸다.

영상이 재생됩니다. 화살표가 하나씩 이어질 때 ‘HT와 TH는 같은 값 1로 간다’는 점을 짚어 줍니다.

버튼을 누르면 정해진 숫자가 나온다

확률변수는 자판기

비유

사진: MApoCE · CC BY-SA

자판기

확률변수

자판기 버튼

→

근원사건 (HH, HT, …)

표시된 가격

→

확률변수 X의 값

가격이 같은 음료가 여러 개

→

HT, TH → 모두 X = 1

버튼 하나에 가격은 하나

→

근원사건마다 X의 값은 하나

자판기 비유: 버튼 = 근원사건, 가격 = X의 값. 같은 가격의 음료가 여러 개일 수 있듯 HT, TH 모두 X=1.

값을 셀 수 있는 확률변수

이산확률변수와 확률분포

이산확률변수

확률변수 X가 취하는 값이 유한개이거나 자연수처럼 셀 수 있을 때

확률분포

X가 취하는 값 x₁, x₂, …, xₙ과 각 값에 대응하는 확률 p₁, p₂, …, pₙ 사이의 관계

확률질량함수

확률분포를 나타내는 함수
P(X = xᵢ) = pᵢ
(i = 1, 2, …, n)

값이 하나, 둘, 셋… 하고 블록처럼 셀 수 있으면 이산확률변수

이산확률변수 X가 값 x를 취할 확률은 기호로 P(X = x)와 같이 나타낸다.

확률분포를 표와 그래프로

X012합계
P(X = x)1/41/21/41
  • X = 0 : TT → 1/4

영상: 막대가 자란 뒤 오른쪽으로 쌓여 높이 1이 됩니다. ‘확률을 모두 더하면 1’을 눈으로 확인시킵니다.

이산확률변수 X의 확률질량함수 P(X = xᵢ) = pᵢ

확률질량함수의 성질

1

0 ≤ pᵢ ≤ 1

각 확률은 0 이상 1 이하

2

p₁ + p₂ + … + pₙ = 1

확률을 모두 더하면 1

3

P(xᵢ ≤ X ≤ xⱼ) = pᵢ + … + pⱼ

구간의 확률은 그 안의 확률을 더한 것

비유

사진: Mohammed Kateregga · CC0 1.0

피자 한 판 = 1

조각을 모두 모으면 다시 한 판

피자 비유: 피자 한 판(=1)을 여러 조각으로 나눠도 조각을 모두 모으면 다시 한 판. 조각 하나는 한 판보다 클 수 없다(0 ≤ p ≤ 1).

주머니에서 공 꺼내기 · 확률분포 구하기

예제

흰 공 3개, 검은 공 2개가 들어 있는 주머니에서 임의로 2개의 공을 동시에 꺼낼 때, 흰 공의 개수를 X라고 하자.

⑴ X의 확률분포를 표로 나타내시오.   ⑵ P(X ≥ 1)을 구하시오.

P(X=0) = ₂C₂ / ₅C₂ = 1/10
P(X=1) = ₃C₁·₂C₁ / ₅C₂ = 6/10
P(X=2) = ₃C₂ / ₅C₂ = 3/10

X012합계
P1/106/103/101

⑵ P(X ≥ 1) = 6/10 + 3/10 = 9/10

영상: 공을 꺼내는 몇 가지 경우를 보여 준 뒤 분포 막대가 나타납니다. 분모 5C2 = 10. 합이 1인지 꼭 확인.

계단과 경사로

이산 vs 연속

비유

사진: John Robert McPherson · CC0

계단 = 이산확률변수

한 칸, 두 칸… 값이 띄엄띄엄

예) 주사위 눈, 앞면의 횟수, 사람 수

경사로 = 연속확률변수

어느 높이에나 설 수 있다 → 범위 안의 모든 실수

예) 키, 몸무게, 기다리는 시간

같은 높이를 오르는 두 방법. 계단은 칸과 칸 사이에 설 수 없지만(이산), 경사로는 어느 높이에나 설 수 있다(연속).

이산에서 연속으로 · 히스토그램이 곡선이 된다

막대를 잘게 쪼개면

연속확률변수에서는 막대의 높이 대신 곡선 아래의 넓이가 확률이 된다.

영상: 막대 5개 → 10 → 20 → 50개로 쪼개면 윗변이 매끄러운 곡선에 가까워집니다. 이 곡선이 확률밀도함수.

기다리는 시간처럼 어떤 범위의 모든 실수 값을 취할 때

연속확률변수

사진: Kaitak89 · CC BY-SA 3.0

10분 간격 지하철역에 아무 때나 도착할 때, 기다리는 시간 X(분)

  • 0 ≤ X ≤ 10인 모든 실수
  • 확률 = 그래프 아래 넓이
영상: 색칠한 넓이가 0부터 10까지 늘어나며 확률이 0 → 1로 변하고, 다시 3에서 멈춰 3/10을 보여 줍니다.

연속확률변수 X (α ≤ X ≤ β)의 확률밀도함수 f(x)

확률밀도함수의 성질

1

f(x) ≥ 0

그래프는 x축보다 아래로 내려가지 않는다

2

y = f(x)와 x축, x = α, x = β로 둘러싸인 넓이 = 1

전체 확률은 1

3

P(a ≤ X ≤ b) = x = a, x = b 사이의 넓이

(단, α ≤ a ≤ b ≤ β)

이산확률변수는 확률의 합, 연속확률변수는 그래프 아래의 넓이로 확률을 구한다.

이산: 확률의 ‘합’ / 연속: 그래프 아래 ‘넓이’. 특정 한 값의 확률은 0이라는 점도 덧붙입니다.

추 = 확률질량함수

무게가 정해진 몇 개의 점에 몰려 있다

모래 = 확률밀도함수

무게가 고르게 퍼져 있다
한 점의 확률은 0, 구간의 넓이로 잰다

추: 무게가 몇 개의 점에 몰려 있다 → 각 값에 확률이 있음. 모래: 무게가 고르게 퍼져 있어 ‘한 알갱이’의 무게는 거의 0 → 구간(넓이)으로 잰다.
