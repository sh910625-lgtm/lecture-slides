manim 영상과 코드

슬라이드에 들어간 애니메이션입니다. 코드를 열어 숫자나 색을 바꾼 뒤 컴퓨터에서 직접 렌더링해 볼 수 있습니다.

내 컴퓨터에서 실행하기

manim은 파이썬 라이브러리라 브라우저에서는 실행할 수 없습니다. 위 1~4번은 같은 색과 모양으로 웹에서 다시 만든 것입니다.

pip install manim
# 같은 폴더에 scenes.py, manim_style.py 를 내려받은 뒤
manim -pql scenes.py CoinDistribution     # 저화질로 빠르게 미리보기
manim -pqh scenes.py CoinDistribution     # 고화질

파일: scenes.py · manim_style.py (글꼴은 Pretendard, LaTeX 없이 동작)
